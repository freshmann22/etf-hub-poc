# iM MTS 임시 디자인 시스템 v0.1 (역추출)

> **상태: 초안 / 추정 다수 포함.** 이 문서는 iM증권 MTS 앱의 **화면 캡처만을** 근거로 역추출한 임시 디자인 시스템입니다.
> 디자인 원본(Figma·토큰 파일·스타일 가이드)이 아니며, 확정된 값이 아닙니다.

## 이 문서가 무엇인가 / 무엇이 아닌가

- **이다**: 캡처에서 눈으로/픽셀로 관찰 가능한 시각 규칙을 정리한 참고 자료.
- **아니다**: 공식 디자인 토큰, 정확한 폰트/여백 사양, 인터랙션·모션·접근성 규격.

**전제(중요)**
1. 캡처는 실제 디자인 원본이나 Figma 파일이 아니다.
2. 정확한 값을 알 수 없는 항목은 단정하지 않는다.
3. 관찰값 / 추정값 / 미확인값을 명확히 구분한다.
4. 이 단계에서는 ETF 허브 애플리케이션 코드를 수정하지 않는다.

## 신뢰도 표기 규약

- **관찰값**: 캡처에서 직접 보이거나 픽셀 측정으로 뒷받침됨.
- **추정값**: 관찰에서 유도했으나 정확한 원본값은 미확인.
- **미확인값**: 캡처로 판단 불가. `open-questions.md`로 이관.
- 확신도: **높음**(3개+ 화면 반복 관찰) / **중간**(1~2개 화면) / **낮음**(단서 부족·해석 개입).

## 측정 방법·한계 (반드시 읽을 것)

- 모든 캡처는 **1179×2556px, iOS 기기(@3x 추정)**. 논리 px = 물리 px ÷ 3 로 환산(추정).
- 색상은 Pillow로 영역 내 **최고 채도 픽셀(잉크색)** 또는 평탄 영역 평균을 추출. 스크린샷 압축·디스플레이(P3 가능성)로 **HEX ±8 오차** 가정.
- 폰트 크기는 글자 잉크 높이 측정 후 환산한 **추정치**이며, 실제 font-size/line-height/weight는 미확인.
- spacing/radius는 소수 지점만 측정, 대부분 육안 추정. **단순 화면 평균 금지** 원칙에 따라 동일 역할 컴포넌트끼리만 비교함.

## 최종 요약 (경영진/에이전트용 1분 브리핑)

- **신뢰도 높은 규칙**: ①상승=빨강·하락=파랑(부호 항상 표기) ②1차 액션/선택 강조색 = 딥네이비 `#183058` ③배경 흰색 + 헤어라인 카드 경계 + 그림자 최소 ④좌우 페이지 여백 ≈ 20px ⑤정보 위계: 큰 볼드 숫자 + 회색 라벨.
- **아직 추정**: 정확한 색 HEX, 폰트 패밀리/weight, 폰트 크기 스케일, spacing/radius 수치, elevation 단계.
- **충돌 사례**: 선택 강조가 화면마다 **네이비 pill(6278·6285)** vs **near-black pill(6275·6276)** 로 갈림. 하락 파랑도 텍스트 `#3880E0` vs 현재가 `#4878D8` 변주.
- **추가 확보 권장**: 빈 상태·오류·검색결과 0건·로딩·다이얼로그·토글/스위치 on·off·버튼 press 상태 캡처.
- **ETF 허브 즉시 적용 가능**: 적/청 등락 규칙, 네이비 vs 민트 정합 확인, 헤어라인·저채도 카드, 숫자 위주 위계, 언더라인 탭. → `do-dont.md`.
- **적용 금지(부적합)**: 주문/매수/매도 버튼·키패드, 장바구니 FAB, 추천 탭, 3D·그라데이션 프로모 카드(6284), 강한 그림자. → `do-dont.md`.
