# Components — iM MTS DS v0.1 (역추출)

> 각 컴포넌트: **관찰된 형태 / 발견 화면 / 확신도 / 미확인(상태·인터랙션)**.
> interaction state(hover/press/disabled/focus), loading, animation은 정적 캡처로 확인 불가 → `open-questions.md`.

---

## 1. Button — 확신도: 중간

| 변형 | 관찰 | 화면 |
|---|---|---|
| Primary(솔리드 네이비) | 배경 `#183058`, 흰 텍스트, 라운드 ~8–12px, 작은 크기 | 6278 "주문"/"현재가" |
| CTA(솔리드 밝은 파랑) | 배경 `#4098F0`, 흰 볼드 텍스트, 큰 폭, 키패드 하단 | 6279 "입력완료" |
| Segmented 액션 | 캡처 내 명확한 사각 secondary 버튼은 드묾 | — |

- 관찰: 1차 버튼은 **작고 솔리드**. 화면을 꽉 채우는 큰 버튼은 키패드 확정("입력완료")에서만.
- **미확인**: press/disabled 색, 최소 터치 타깃, 로딩 스피너.
- **ETF 허브 주의**: "주문/매수/매도" 버튼은 관찰되나 **채택 금지**(콘텐츠 정책). → `do-dont.md`.

## 2. Text link — 확신도: 중간

- 형태: 텍스트 + `>` 셰브런. "더보기 >", "자세히보기 >", "전체 보기", "채우기 >". (관찰, 다수 화면)
- 색: 대체로 회색/진회색 텍스트 + 회색 셰브런. 파랑 링크색으로 강하게 칠하지 않음. (관찰)
- 우측 상단 "전체 보기"류는 섹션 헤더 우측 정렬. (관찰, 6281·6283·6284)
- **미확인**: 방문/press 상태, 밑줄 사용 여부.

## 3. Card — 확신도: 중간

- 흰 표면 + 큰 라운드(~16–20px) + 헤어라인, 그림자 최소. (관찰, 다수)
- 내부 구조: 좌측 라벨/아이콘, 우측 정렬 수치. 카드 안에 서브 카드/분할선. (관찰)
- 유형: ①요약 카드(지수·자산·시장요약) ②정보 카드(뉴스·펀드 랭킹 항목) ③프로모 카드(6284, **부적합**).
- **미확인**: press시 눌림/리플, 카드 전체 탭 가능 여부.

## 4. List row — 확신도: 높음

관찰된 공통 골격 (6277·6281·6282·6285에서 반복):

```
[원형 로고 ⌀~48–56] [종목/타이틀(볼드)]            [우측 정렬 값 블록]
                     [코드/부가라벨(회색·작게)]      [% (색·볼드)] 
                                                     [현재가/서브(회색)]
```

- 좌측 원형 브랜드 로고(⌀ 대략 48–56 논리 px 추정). (관찰)
- 우측: **% 변화(적/청·볼드)** 위, **가격/서브값(회색)** 아래. (관찰, 높음)
- 행 구분: 헤어라인 또는 카드 그룹. (관찰)
- 변형: 뉴스 row는 로고 대신 썸네일/출처+시각. 랭킹 row는 좌측에 순위 숫자. (관찰)
- **미확인**: press 하이라이트, 스와이프 액션, 최소 행 높이.

## 8. Search field — 확신도: 중간

- 형태: 라운드(캡슐에 가까운 큰 라운드) + 좌측 돋보기 아이콘 + 회색 플레이스홀더. (관찰, 6282 + hub)
- 배경: 아주 옅은 회색 또는 흰색 + 헤어라인. (관찰)
- 6282는 검색 필드 + 우측 날짜 피커 칩 + 필터 아이콘 조합. (관찰)
- **미확인**: 포커스 상태, 입력중/삭제 버튼, 자동완성.

## 9. Bottom sheet — 확신도: 중간(6279 단일 근거)

- 상단 **그랩 핸들**(가운데 짧은 회색 바) + 큰 상단 라운드(~20–24px). (관찰)
- 우측 상단 **닫기 X**. (관찰)
- 헤더: 계좌/타이틀(회색 서브 + 볼드 메인). (관찰)
- **딤 배경**: 뒤 화면을 어둡게 덮음. (관찰)
- 하단에 숫자 키패드 결합(계좌 비밀번호). (관찰)
- **미확인**: 드래그 스냅 포인트, 높이 단계, 열림/닫힘 모션. 근거 화면 1개뿐.

## 10. Toast — 확신도: 낮음~중간

| 유형 | 관찰 | 화면 |
|---|---|---|
| 오버레이 토스트 | 반투명 어두운 라운드 박스, 중앙, "고객님의 최근 접속시간은 …" | 6279 |
| 인라인 개선 배너 | 옅은 배경 바 + "기능개선" 뱃지 + 텍스트 + 닫기 `×` | 6275 |

- **미확인**: 표시 시간, 등장/퇴장 애니메이션, 위치 규칙(상단/하단), 성공/오류 토스트 구분.

## 11. Dialog — 확신도: 없음(캡처 부재)

- **캡처에 명확한 모달 다이얼로그(확인/취소 2버튼 팝업)가 없음.** 바텀시트+키패드가 가장 근접.
- 규칙 창작 금지 → 전부 `open-questions.md`.

## 12. Price & return indicator — 확신도: 높음

관찰된 표기 규칙(6275·6277·6278·6281·6285 반복):

- 구성: **부호 삼각형(▲/▼) + 절대변화 + 부호(+/−) 퍼센트**. 예 `▲ 8.63 +0.13%`, `▼ 10.07 −1.26%`.
- 색: 상승 빨강 `#DA463C`, 하락 파랑 `#3880E0`. (높음)
- 현재가(대형)는 등락색과 동일 계열로 크게. 예 호가 22.0000(파랑). (관찰)
- 우측 정렬 정렬(list/호가). 퍼센트가 위, 절대가/거래대금이 아래인 경우가 많음. (관찰)
- **색만으로 구분하지 않고 반드시 부호/삼각형 동반** → 접근성상 바람직(단, 실제 대비/보이스오버는 미확인).
- ETF 허브 계약(up=red, down=blue, 부호 표기)과 **완전 일치** → 즉시 적용 가능. `do-dont.md`.
