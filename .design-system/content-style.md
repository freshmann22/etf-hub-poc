# Content Style — iM MTS DS v0.1 (역추출)

> 캡처에서 관찰된 문구·숫자·부호 표기 규칙. 확신도 표기. 캡처에 없는 규칙은 창작하지 않음.

---

## 1. 숫자·금액 표기 — 확신도: 높음

- **천단위 콤마**: `6,815.56`, `38,420원`, `18,500,648원`. (관찰, 다수)
- **한국식 큰 단위**: `6조 3,820억원`, `1조 2,400억원`, `980억원`. 조/억 혼용 표기. (관찰)
- **통화 접미사**: 원화 `…원`, 해외 `USD`/`22.0000`(소수 4자리, 해외 ETF). (관찰, 6278)
- **퍼센트**: 소수 2자리 `+0.13%`, `−1.26%`, `29.98%`. (관찰)
- **개수 단위**: `14개`, `7개`, `3개`. (관찰, 6275)

## 2. 등락 부호 표기 — 확신도: 높음

- **삼각형 + 부호 동반**: `▲ 8.63 +0.13%`, `▼ 10.07 −1.26%`. 색(적/청) + 기호를 **함께** 사용. (관찰, 반복)
- 상승 `+`/`▲`, 하락 `−`/`▼`, 보합 `—`(회색). (관찰)
- **색 단독 사용 안 함** — 부호로도 방향을 알 수 있음. (관찰) → 접근성상 바람직.

## 3. 톤 & 보이스 — 확신도: 중간

- **친근한 구어체 종결**: "…살펴보세요", "…볼 수 있어요", "…자극했어요"(hub), "…추정돼요". (관찰)
- 질문형 후킹 카피: "오늘은 무슨 일이?", "무엇을 보고 싶으세요?". (관찰, MTS·hub)
- 안내 톤은 **정보 제공형**. 강한 명령/과장 억제(단, 마케팅 화면 6284·6285는 예외적으로 세일즈 톤).

## 4. 라벨링 관례 — 확신도: 중간

- **라벨(회색·작게) + 값(볼드)** 페어: `전체 거래대금 / 6조 3,820억원`, `순자산 / 1조 2,400억원`, `총보수 / 0.45%`. (관찰)
- 종목 표기: `종목명(볼드) + 코드(회색, 6자리)` 예 `KODEX 반도체 / 091160`. (관찰)
- 시각·기준 표기: `기준 2026.07.14 장마감 USD`, `05.12 15:30`, `2026.06.25 08:45:58`. (관찰)

## 5. 카테고리/테마 명명 — 확신도: 중간

- 테마·분류는 짧은 명사구: `반도체`, `2차전지`, `미국 기술주`, `레버리지·인버스`, `AI·로봇`. **가운뎃점 `·`** 로 복합어 결합. (관찰)

## 6. ETF 허브 콘텐츠 정책과의 관계 — 확신도: 높음(정책 기준)

MTS 캡처에는 아래 **유도성/거래성 문구·요소가 존재하나, ETF 허브에는 채택 금지**(프로젝트 콘텐츠 정책):

| MTS에서 관찰 | ETF 허브 |
|---|---|
| "주문", "매수/매도", "지정가", 수량 입력 | ✗ 금지 (거래 유도) |
| "추천"(펀드 탭), "적극투자형 >"(투자성향) | ✗ 금지 (추천/유도) |
| "가입", 장바구니 담기 | ✗ 금지 |
| "▲ 5% 이상 급등" 자극 문구 | △ 신중 (사실 전달형만) |

- 반대로 **차용 권장**: 등락 부호·색 규칙, 라벨+값 페어, 천단위/조·억 표기, 친근한 정보 톤. (즉시 적용 가능)
- ETF 허브 필수 카피(샘플데이터 고지, 검색 플레이스홀더, 빈 상태 문구)는 `INTERFACE_CONTRACT.md`가 우선하며 본 문서는 표기 스타일만 참고.
