# Foundations — iM MTS DS v0.1 (역추출)

> 모든 값은 캡처(`sample/iM_MTS/`) 근거. 관찰/추정/미확인과 확신도를 각 항목에 표기.
> HEX는 스크린샷 픽셀 측정값으로 **±8 오차** 가정. 논리 px = 물리 px ÷ 3 (iOS @3x 추정).

## 1. Color tokens

### 1-1. 시맨틱 — 등락 (semantic: up/down) — **확신도: 규칙 높음 / HEX 중간**

| 토큰(제안) | 의미 | 관찰 HEX(범위) | 권장값 | 발견 화면 | 근거 |
|---|---|---|---|---|---|
| `--color-up` | 상승/양수 | `#D04030`–`#DC4940` | **`#DA463C`** | 6275,6277,6278,6281,6285 (5+) | 코스피 +0.13%, 급등 5%, 호가 매도, 수익률 51.53% 등에서 반복 |
| `--color-down` | 하락/음수 (텍스트·% 변화) | `#3880E0`–`#3B82E5` | **`#3880E0`** | 6275,6277,6281 (3+) | 코스닥 −1.26%, KODEX −2.08%, 선물 −0.32% |
| `--color-down-strong` | 하락 현재가(대형 숫자) | `#4878D8` | `#4878D8` | 6278 | 호가 상단 현재가 22.0000, 매수 호가 |

- **핵심 규칙(높음)**: 상승=**빨강**, 하락=**파랑** (한국시장 관례). ETF 허브 계약과 일치.
- **예외/변주(관찰)**: 하락색이 텍스트에서는 `#3880E0`, 대형 현재가에서는 약간 더 인디고인 `#4878D8`. 상태 차이가 아니라 **컴포넌트별 색 변주**로 보임 → `open-questions.md`.
- 상승/하락 텍스트에는 항상 부호(`+`/`−`)와 삼각형(`▲`/`▼`)이 동반됨. 색만으로 구분하지 않음 → `content-style.md`.

## 2. Typography scale — **확신도: 위계 높음 / 수치 낮음(추정)**

측정: 글자 잉크 높이(물리 px) → ÷3 논리 px. font-size는 잉크높이 ÷ ~0.72(한글 글자높이 비율) 로 **추정**.

| 역할(제안 토큰) | 예시 | 잉크높이(논리 px) | 추정 font-size | 관찰 weight | 확신도 |
|---|---|---|---|---|---|
| `type-display` | 현재가 22.0000, 지수 6,815.56 | ~28 | ~34–40px | Bold/Heavy | 중간 |
| `type-hero` | 히어로 카피 "오늘은 무슨 일이?" | ~30 | ~40px+ | Bold | 낮음(마케팅) |
| `type-title` | 화면 타이틀(관심종목, 종합뉴스) | ~19 | ~24–26px | Bold | 중간 |
| `type-section` | 섹션 헤더(종목 랭킹, 내 자산) | ~19–20 | ~22–24px | Bold | 중간 |
| `type-body-strong` | list row 종목명, 수익률 % | ~17 | ~20–22px | Semibold/Bold | 중간 |
| `type-body` | 본문/설명 | 추정 | ~15–16px | Regular | 낮음 |
| `type-label` | 탭 라벨(랭킹) | ~14 | ~17–19px | Medium | 낮음 |
| `type-caption` | 코드번호·타임스탬프·부가 라벨 | 추정 | ~12–13px | Regular, 회색 | 낮음 |

- **높은 확신도(위계)**: display > title/section > body-strong > body > label > caption 의 **6~7단 위계**가 일관됨.
- **weight 대비 규칙(높음)**: 숫자·핵심 값은 굵게, 라벨·단위·부가정보는 얇은 회색. 정보 밀도가 높아도 굵기/색 대비로 위계를 만든다.
- **폰트 패밀리: 미확인.** 한글은 iOS 시스템 폰트(Apple SD Gothic Neo) 또는 Pretendard류 지오메트릭 산세리프로 보이나 확정 불가. 숫자는 약간 무거운 산세리프. → `open-questions.md`.
- **line-height, letter-spacing: 미확인.**

## 3. Spacing scale — **확신도: 낮음(추정)**

- 정밀 측정은 좌측 여백 등 소수 지점만 수행. 대부분 육안 추정이며 **단순 평균하지 않음**.
- 관찰: 4의 배수 리듬으로 보이는 간격이 반복(카드 내부 패딩, 항목 간격). 확정 불가.

| 제안 토큰 | 추정값(논리 px) | 근거/비고 |
|---|---|---|
| `space-page` | **~20px** | 좌측 콘텐츠 인셋 측정 ≈ 23px(6277). 좌우 페이지 여백. **중간** |
| `space-card-pad` | ~16–20px | 카드 내부 상하좌우 패딩(육안) |
| `space-row-gap` | ~12–16px | list row 항목 간 세로 간격(육안) |
| `space-section-gap` | ~24–32px | 섹션 블록 사이 간격(육안) |
| `space-inline-sm` | ~8px | 라벨-값, 아이콘-텍스트(육안) |

→ 정확한 spacing 토큰은 추가 측정 필요. `open-questions.md`.

## 5. Border & divider — **확신도: 중간**

- **카드 경계**: 눈에 거의 안 띄는 헤어라인(≈ `#EEEEEE`, 1px 추정). 강한 테두리 없음. (관찰)
- **리스트 구분선**: 행 사이 얇은 회색 라인 또는 카드 그룹핑으로 분리. 두꺼운 divider 없음. (관찰)
- **outline pill/칩**: 미선택 상태는 얇은 회색 테두리(`#DDDDDD`~`#EEEFF0` 추정) + 흰 배경. (관찰, 6275·6285)
- **탭 인디케이터**: 활성 탭 하단 **언더라인**(검정/네이비, 2~3px 추정) + 활성 텍스트 진하게. (관찰, 6275·6278·6282·6285)

## 6. Shadows — **확신도: 중간**

- **관찰: 그림자 최소.** 카드는 대부분 헤어라인/미세한 회색 대비로 분리하며, 강한 드롭섀도우는 쓰지 않음.
- 예외: **바텀시트/캐러셀 카드**에 아주 옅고 넓은 상단 그림자(경계감)만 관찰(6279 시트, 6275 지수 카드). blur 크고 alpha 낮음(추정).
- 강한/짙은 그림자, 다층 elevation은 관찰되지 않음. 정확한 그림자 파라미터(x/y/blur/spread/alpha)는 **미확인** → `open-questions.md`.
- 제안 토큰(추정): `shadow-sheet: 0 -2px 12px rgba(0,0,0,0.06)`, `shadow-card: none 또는 0 1px 4px rgba(0,0,0,0.04)`.

## 7. Page margins — **확신도: 중간**

- 좌우 콘텐츠 여백 ≈ **20px 논리 px**(측정 23px @6277). (관찰)
- 카드 컨테이너는 이 여백 안에서 풀-와이드로 배치, 카드 내부에 다시 패딩. (관찰)
- 상단: 상태바(시간·배터리) 아래 히어로/타이틀 영역. 하단: **고정 탭바** 위로 콘텐츠. 세이프에어리어 존중(추정).

## 8. Elevation hierarchy — **확신도: 중간**

관찰된 층위(낮음→높음):

1. **배경면** — 흰색 페이지.
2. **표면/카드** — 흰 카드 + 헤어라인, 그림자 거의 없음.
3. **고정 하단 탭바** — 페이지 위, 상단 경계선.
4. **인라인 배너/토스트** — 콘텐츠 흐름 위(6275 개선 배너, 6279 상단 토스트).
5. **바텀시트 + 딤 배경** — 최상위. 배경을 어둡게 덮고(dim), 시트가 아래에서 올라옴(6279).

- elevation은 **그림자 강도가 아니라 "덮기(dim)·위치"로 표현**됨. z-축 그림자 단계는 뚜렷하지 않음. (관찰)
