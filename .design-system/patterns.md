# Patterns — iM MTS DS v0.1 (역추출)

> 반복 관찰되는 레이아웃/구성 패턴. 각 항목 확신도 표기. 화면 단순 평균이 아니라 동일 역할 비교로 도출.

---

## 1. 화면 골격 (screen skeleton) — 확신도: 높음

```
[상태바]                         ← OS
[헤더: 뒤로/타이틀 (+우측 액션 아이콘)]
[스크롤 콘텐츠: 섹션 스택]
  섹션 = [섹션 헤더 (좌: 제목 볼드 / 우: 더보기·전체보기 링크)]
         [카드 or 리스트 본문]
[고정 하단 탭바]                 ← 홈 계열
```

- 홈 계열(6275·6276)은 상단 **히어로 이미지 배너** + 그 위에 흰 시트가 겹쳐 올라오는 구성. (관찰)
- 상세/리스트(6277·6278·6282·6283·6285)는 **뒤로가기 + 화면 타이틀 + 우측 액션 아이콘**(하트·검색·더보기·새로고침). (관찰)

## 2. 섹션 헤더 패턴 — 확신도: 높음

- 좌측 **볼드 섹션 제목**, 우측 **텍스트 링크(더보기 / 전체 보기 `>`)**. (6281·6283·6284 반복)
- 제목 아래 보조 설명 회색 한 줄이 붙기도 함("어떤 테마에 자금이 몰렸는지 볼 수 있어요"류 — hub). (관찰)

## 3. 카드 그룹 / 요약 카드 — 확신도: 높음

- 상단에 **요약 카드**(지수·자산·시장요약)를 두고, 그 아래 **리스트/디테일**로 전개. (관찰, 다수)
- 요약 카드는 다지표를 **작은 라벨(회색) + 큰 값(볼드)** 그리드로 배치. (6275·6276·6283)
- 카드 간 구분은 그림자 아닌 **여백 + 헤어라인**. (관찰)

## 4. 가로 캐러셀 — 확신도: 중간

- 지수 카드(6275), 프로모 카드(6284), 테마 카드(hub)는 **가로 스크롤 + 페이지 도트**. (관찰)
- 우측에 다음 카드가 살짝 보이는 **peek** 처리로 스크롤 가능성 암시. (관찰, 6275)
- 페이지 인디케이터는 하단 중앙 점(활성 진하게). (관찰, 6284)

## 5. 탭 전환 패턴 — 확신도: 높음

- 데이터 필터/뷰 전환은 **언더라인 탭**으로 통일(상승/하락/거래량…, 호가/체결/차트…). (관찰)
- 기간 전환은 **세그먼트/토글**(일·주·월·3분·10틱 @6280). (관찰)
- 탭이 넘치면 **가로 스크롤 + 우측 `▾` 더보기**. (관찰, 6278)

## 6. 리스트 행 정보 위계 — 확신도: 높음

- 좌: 정체성(로고/순위/종목명). 우: **정량 값(등락% 볼드+색, 가격/거래대금 회색)**. (관찰, 반복)
- 한 행에 2~3레벨 위계를 **크기·굵기·색**만으로 구성(장식 최소). (관찰)

## 7. 등락 색·부호 패턴 — 확신도: 높음

- 상승 빨강 / 하락 파랑 + **항상 부호·삼각형 동반**. 시장요약(상승 14개=빨강, 하락 7개=파랑, 보합=회색). (관찰, 다수)
- 보합/중립은 **회색 + `—`**. (관찰, 6275·6276)

## 8. 딤+바텀시트 오버레이 — 확신도: 중간

- 추가 입력/상세는 **배경 딤 + 하단 시트**(그랩 핸들·X)로 올림. (관찰, 6279)
- 민감 입력(비밀번호)은 시트 + 전용 숫자 키패드. (관찰) — ETF 허브에는 해당 흐름 없음.

## 9. 인라인 배너/토스트 패턴 — 확신도: 중간

- 상단/콘텐츠 흐름에 **닫기 가능한 옅은 배너**로 안내·개선 고지("기능개선 … ×"). (관찰, 6275)
- 시스템 안내는 **중앙 반투명 토스트**(자동 소멸 추정). (관찰, 6279)

## 10. ETF 허브 적용 매핑 (참고) — 확신도: 중간

hub_sample(우리 앱)과 대조한 **구조적 참고**(색·문구 그대로 이식 아님):

| MTS 패턴 | ETF 허브 대응 | 비고 |
|---|---|---|
| 요약 카드 + 리스트 전개 | "오늘의 ETF 시장" 카드 + "지금 많이 움직인 ETF" | 정합 |
| 언더라인 탭 | 랭킹 탭(상승/하락/거래 급증/변동성) | MTS식 언더라인 권장(현재 hub는 세그먼트 혼용) |
| list row(로고+명 / %+가격) | ETF row | 정합 |
| 도넛+범례(6283) | (해당 시) 구성 비중 | 참고 |
| 딤+바텀시트(6279) | ETF 프리뷰 시트(sample1) | 구조 참고, 단 주문/키패드 제외 |
| 프로모 3D 카드(6284) | ✗ | **채택 금지** |

> 브랜드색 주의: MTS 주색은 네이비 `#183058`이나 ETF 허브는 계약상 iM Mint `#00C7A9`가 단일 포인트색. **민트는 UI 강조 전용, 등락 색으로 쓰지 않음** — MTS의 적/청 등락 규칙만 차용. 세부는 `do-dont.md`.
