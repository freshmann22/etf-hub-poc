# Review Checklist — iM MTS DS v0.1 (역추출)

> ETF 허브 화면을 이 임시 DS 기준으로 점검할 때 쓰는 QA 체크리스트.
> "확정 규칙"은 확신도 높음 항목만. 나머지는 참고. 코드 수정 없이 검토용.

---

## A. 색상 & 등락 (확신도 높음 — 필수)

- [ ] 상승/양수 = 빨강(`#DA463C` 계열), 하락/음수 = 파랑(`#3880E0` 계열)인가?
- [ ] 등락에 **부호(+/−)와 삼각형(▲/▼)** 이 항상 함께 있는가? (색만으로 구분 금지)
- [ ] 보합/중립은 회색 + `—` 인가?
- [ ] 강조색은 계약대로 **iM Mint `#00C7A9`** 만 쓰고, 등락 색과 섞지 않는가?
- [ ] MTS 네이비/프로모 파랑을 강조색으로 잘못 이식하지 않았는가?
- [ ] 배경은 순백, 텍스트는 primary `#212121`/secondary `#616263`/tertiary `#A2A2A2` 위계를 지키는가?

## B. 타이포 & 위계 (확신도 중간)

- [ ] 큰 볼드 숫자 + 회색 라벨의 위계가 있는가?
- [ ] 화면 타이틀 > 섹션 헤더 > 본문강조 > 본문 > 라벨 > 캡션 위계가 구분되는가?
- [ ] 핵심 값만 굵게, 단위/부가정보는 얇은 회색인가?
- [ ] (미확인) 폰트 크기/weight는 임의 확정하지 않았는가?

## C. 레이아웃 & 스페이싱 (확신도 중간)

- [ ] 좌우 페이지 여백 ≈ 20px를 지키는가?
- [ ] 카드 분리를 그림자 대신 **여백 + 헤어라인**으로 하는가?
- [ ] 섹션 = 헤더(좌 제목 / 우 더보기 `>`) + 본문 구조인가?
- [ ] 요약 카드 → 리스트 전개 흐름을 따르는가?

## D. 컴포넌트 (확신도 항목별)

- [ ] list row: 좌(로고/순위+명+코드) / 우(%색볼드+가격회색) 정렬인가? (높음)
- [ ] 탭: 언더라인형(활성 진하게+언더라인)인가? (높음)
- [ ] pill/칩: 선택 솔리드 / 미선택 회색 테두리인가? (중간)
- [ ] 뱃지: 저채도 틴트 배경인가? (중간)
- [ ] 카드/시트: 큰 라운드 + 헤어라인 + 그림자 최소인가? (중간)
- [ ] 바텀시트: 그랩 핸들 + 상단 라운드 + X + 딤 배경인가? (중간)

## E. 라운드 & 보더 (확신도 중간)

- [ ] pill류는 완전 캡슐인가?
- [ ] 카드/시트는 부드러운 큰 라운드(직각 모서리 지양)인가?
- [ ] 테두리는 헤어라인(≈`#EEEEEE`)으로 은은한가?

## F. 콘텐츠 표기 (확신도 높음)

- [ ] 천단위 콤마 / 조·억 단위 / 소수 자리수 규칙이 일관적인가?
- [ ] 종목 = 명(볼드) + 코드(회색) 표기인가?
- [ ] 톤이 정보 전달형(친근한 구어체)인가? 과장/유도 표현이 없는가?

## G. ETF 허브 금지 항목 (확신도 높음 — 필수)

- [ ] 주문/매수/매도 버튼·키패드·수량 입력이 **없는가**?
- [ ] 장바구니/FAB/가입/추천 요소가 **없는가**?
- [ ] 3D·그라데이션 프로모 카드, 강한 그림자가 **없는가**?
- [ ] 자극/투자유도 문구가 **없는가**? (사실 전달형만)
- [ ] 제3자 브랜드 로고 색을 UI 토큰으로 쓰지 **않았는가**?

## H. 확인 불가 항목 (검토 시 "판단 보류"로 표시)

- [ ] 인터랙션 상태(hover/press/disabled/focus) — 캡처 근거 없음
- [ ] 로딩/스켈레톤/애니메이션 — 근거 없음
- [ ] 빈 상태 / 오류 / 검색결과 0건 — 근거 없음
- [ ] 접근성(대비비·터치타깃·보이스오버) — 근거 없음
- [ ] 반응형/다크모드 — 근거 없음

> H 항목은 통과/실패로 판정하지 말 것. `open-questions.md`로 이관해 원본/추가 캡처로 확인.
