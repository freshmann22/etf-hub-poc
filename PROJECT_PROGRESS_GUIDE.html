3분 요약

지금 어디까지 왔나요?

핵심 탐색 흐름은 작동합니다. 데이터의 범위와 최신성은 아직 확대 중이며, 실제 투자 주문을 위한 완성 서비스 단계는 아닙니다.

사용자 관점

무엇이 달라지나요?

종목 코드나 금융 용어를 먼저 알아야 했던 과정을, “내가 무엇을 원하는지”에서 출발하도록 바꿉니다.

원하는 조건을 말합니다

예: “매달 배당을 주는 미국 ETF”, “반도체지만 레버리지는 제외”.

조건을 알아서 정리합니다

지역, 산업, 운용 방식, 배당 특징 등으로 문장을 해석하고 후보를 좁힙니다.

근거와 상세를 확인합니다

관련 테마 설명, 실제 편입 종목, 기본 정보로 이어져 결과를 스스로 검토할 수 있습니다.

구현 내용

이번에 만든 다섯 가지

기술 이름보다 사용자에게 어떤 변화가 생겼는지를 중심으로 정리했습니다.

01

ETF 1,141개를 같은 기준으로 정리

각 상품을 자산 종류, 투자 지역, 산업·테마, 운용 전략, 배당 특징의 다섯 관점으로 분류했습니다. 서로 다른 이름의 상품도 같은 기준으로 비교할 토대입니다.

완료
02

일상 문장으로 찾는 ‘역방향 검색’

상품명을 모르는 상태에서도 원하는 조건을 문장으로 입력할 수 있습니다. 규칙 기반 해석이 기본이며, 필요할 때 AI 해석을 보조로 붙일 수 있게 설계했습니다.

기본 기능 완료
03

운용사 공식 구성종목 우선 사용

KODEX와 TIGER는 운용사가 공개한 자료에서 어떤 종목을 담고 있는지 가져옵니다. 공식 자료를 구하지 못하면 저장된 대체 자료를 쓰거나 “정보 없음”을 표시합니다.

2개사 연결
04

테마를 빠르게 이해하는 브리핑

반도체 같은 태그를 고르면 핵심 요약과 관련 ETF를 함께 보여줍니다. 미리 검수한 글, AI 생성 글, 둘을 섞는 방식으로 운영할 수 있고 출처 상태를 숨기지 않습니다.

기능 완료
05

변경할 때마다 자동으로 점검

검색, 데이터 형태, 서버 응답, 브리핑 정책 등을 167개 자동 검사로 확인합니다. GitHub에서도 같은 검사를 실행하도록 연결했습니다.

신뢰 범위

믿어도 되는 것과 아직 아닌 것

PoC를 완성 서비스처럼 보이게 포장하지 않았습니다. 확인된 범위와 남은 위험을 구분합니다.

현재 확인된 것

  • 1,141개 ETF의 탐색용 분류 데이터가 연결되어 있습니다.
  • 검색·분류·서버·브리핑 정책 등 자동 검사 167개가 통과합니다.
  • KODEX와 TIGER 대표 상품은 공식 공개자료 연결을 검증했습니다.
  • 공식 자료 실패 시 무리하게 값을 꾸미지 않는 대체 경로가 있습니다.

아직 주의할 것

  • 실시간 시세·뉴스·분배금 전체가 연결된 상태는 아닙니다.
  • KODEX·TIGER 외 운용사의 공식 구성종목 연결은 후속 작업입니다.
  • 유료 AI를 실제 운영 키로 장시간 호출하는 검증은 하지 않았습니다.
  • 화면의 일부 값은 PoC 샘플이며 투자 판단 자료로 쓰면 안 됩니다.

이 프로젝트는 투자 추천 서비스가 아닙니다. 정보 탐색 경험과 데이터 연결 가능성을 검증하는 시제품입니다.
