# DECISION LOG

## 확정된 결정

### D-001 — 1차 PoC 대상

최종 ETF 허브 전체가 아니라 `ETF 허브 메인화면`을 구현한다.

### D-002 — 핵심 목적

기능 완성보다 화면의 첫인상, 정보 구조, 탐색 흐름을 우선 검증한다.

### D-003 — 데이터

모든 데이터는 로컬 가상 데이터로 구성한다.

### D-004 — 외부 연결

외부 API, 실제 시세, 뉴스, 공시, 리서치, 계좌, 로그인은 연결하지 않는다.

### D-005 — 거래 기능

매수·매도·주문 CTA를 구현하지 않는다.

### D-006 — 추천 기능

ETF 추천, 투자 타이밍, 목표가격, 목표수익률을 제공하지 않는다.

### D-007 — 주요 화면 콘텐츠

- 오늘의 ETF 시장
- ETF 히트맵
- 많이 움직인 ETF
- 오늘 주목할 테마
- 종목으로 ETF 찾기
- 같은 테마 ETF 비교
- 뉴스·공시·리서치
- ETF 프리뷰 바텀시트

### D-008 — 상세화면

ETF 상세화면 전체는 2차 PoC로 이관한다.

### D-009 — 가격 변동 해석

차트, 변곡점, 이벤트 마커, 이날 왜 움직였나요, 추정 기여도는 2~3차 PoC로 이관한다.

### D-010 — 구현 형태

로컬 브라우저에서 실행 가능한 소규모 프론트엔드 PoC로 구현한다.

### D-011 — 멀티에이전트

기존 `/multi-agent-start` 템플릿을 사용하며 계획 승인 후 S2~S9는 중단 조건이 없는 한 자동 진행한다.

## Fable이 실행 계획에서 결정해도 되는 항목

다음은 사용자 재승인 없이 실행 계획에서 제안할 수 있다. 단, 계획 승인 전 명시해야 한다.

- 순수 HTML/CSS/JavaScript와 경량 프레임워크 중 선택
- 차트 라이브러리 사용 여부
- 파일 세분화 수준
- CSS 토큰 구조
- 테스트 러너
- 데이터 fixture 파일 형식
- 히트맵을 비대칭 카드 그리드로 구현하는 구체적 방식
- 모바일 카드 캐러셀 사용 여부
- 샘플 ETF와 테마의 구체적 구성

## 사용자에게 다시 물어야 하는 항목

다음 상황이 발생할 경우에만 확인한다.

- iM증권의 정확한 디자인 토큰이나 내부 자산을 사용해야 하는 경우
- 회사 로고, 내부 아이콘, 비공개 UI 가이드가 필요한 경우
- 실제 데이터 또는 사내 시스템 연결이 필요한 경우
- 유료 패키지 또는 과금형 API가 필요한 경우
- 배포나 외부 공유가 필요한 경우
- 기존 파일을 파괴적으로 변경해야 하는 경우
