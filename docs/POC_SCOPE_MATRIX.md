## 범위 판정 원칙

1. 메인화면의 시각적 정체성과 탐색 흐름에 직접 필요한 기능만 1차 PoC에 포함한다.
2. 가격 차트, 기여도, 변곡점, 위험요약 등 ETF 상세 해석 기능은 후속 단계로 분리한다.
3. 실제 데이터와 외부 시스템이 필요한 항목은 UI 프리뷰만 제공하거나 제외한다.
4. 샘플 구현이 최종 기능 완료를 의미하지 않도록 문서와 화면에 명확히 표시한다.
