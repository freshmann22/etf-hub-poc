# ETF 허브 PoC — 프로젝트 브리핑 (콘텐츠 확장 논의용)

> 이 문서는 **Claude 챗에 프로젝트를 설명하고, 앱에 추가할 "콘텐츠"를 함께 기획·논의**하기 위한 자립형 요약입니다.
> 코드베이스를 모르는 상대(사람/AI)가 이 문서만 읽고도 맥락을 잡을 수 있도록 작성했습니다.
> 최종 갱신: 2026-07-16

---

## 1. 한 줄 소개

**ETF 허브** — 모바일(390×844) 화면에 최적화된 **한국 ETF 탐색·이해 앱**의 PoC(개념검증).
투자 권유 없이, ETF를 **발견하고 이해하는 것**에 초점을 둡니다.

## 2. 무엇을 만들고 있나 (제품 관점)

두 개의 화면 축이 있습니다.

### ① 메인 허브 (`index.html`)
사용자가 앱을 열었을 때 보는 홈. 구성 섹션:
- **시장 요약** — 기간별 상승/하락/보합 집계
- **히트맵** — 수익률·거래대금 강도를 색·크기로 표현
- **랭킹** — 등락률/거래대금 등 탭별 상위 ETF
- **종목→ETF 역검색** — "삼성전자를 담은 ETF는?" 식 역방향 탐색
- **테마 카드** — 반도체·방산·2차전지·AI로봇·조선 등 테마별 묶음
- **비교** — ETF 간 나란히 비교
- **콘텐츠 피드** — 뉴스/리서치/공시 (← *이번 논의의 핵심 확장 대상*)
- **바텀시트** — 개별 ETF 상세 요약

### ② 탐색→상세 프로토타입 (`etf-explore.html`)
카테고리·칩으로 **탐색**하고, 개별 ETF **상세**(요약/구성종목/수익률/배당 탭)로 들어가는 신형 화면.
iM 디자인 시스템 + Spoqa Han Sans Neo 폰트로 스타일링. 실데이터(실시간 시세/캔들/구성종목/메타데이터)를 소비하되, 없는 값은 정직하게 샘플로 폴백.

## 3. 핵심 원칙 (콘텐츠 기획 시 반드시 지킬 것)

이 앱에는 **콘텐츠 정책(content policy)** 이 코드 테스트로 강제되어 있습니다. 새 콘텐츠도 이 선을 지켜야 합니다.

- 🚫 **투자 권유·유도 금지** — "추천", "지금 사야", "매수/매도 타이밍", "목표가격", "자금 유입" 계열 문구 금지 (자동 테스트가 문자열을 스캔해 차단).
- 🚫 **실주문 기능 없음** — 매수/매도 버튼은 비활성 플레이스홀더(탭하면 "후속 범위" 안내). 실제 주문 흐름 없음.
- ✅ **등락은 부호로** — 색만이 아니라 `+`/`-` 부호 병기. **상승=빨강, 하락=파랑** (한국 관례).
- ✅ **정직한 데이터** — 값이 없으면 지어내지 않고 `[샘플]` 태그 또는 "정보 없음"으로 표기.
- 🎨 **브랜드 색 = iM 민트 `#00C7A9`** (UI 액센트 전용 — 활성 탭·선택·포커스. 등락 색과 절대 혼용 금지).
- 📱 뷰포트 **390×844** 고정, 가로 스크롤 0 유지.

## 4. 현재 콘텐츠 자산 (지금 있는 것)

메인 허브의 콘텐츠 피드는 현재 **샘플 고정 데이터** 14건으로 구성:

| 유형 | 개수 | 예시 제목 |
|---|---|---|
| `news` (뉴스) | 8 | "메모리 업황 개선 기대감 속 KODEX 반도체 거래 증가" |
| `research` (리서치) | 3 | (테마·업황 해설형) |
| `disclosure` (공시) | 3 | (전자공시 연계) |

각 콘텐츠 항목의 데이터 구조:
```js
{
  id: 'news-001',
  type: 'news',                          // news | research | disclosure
  title: '...',
  summary: '...',                        // 존댓말·해설형, 권유 표현 없음
  publishedAt: '2026-07-10T08:30:00+09:00',
  relatedEtfIds:  ['etf-003', 'etf-004'],   // 관련 ETF (탭 이동 연결)
  relatedStockIds:['stock-000660'],         // 관련 종목
  relatedThemeIds:['theme-semi'],           // 관련 테마
  source: '샘플 뉴스',
}
```
> 콘텐츠는 ETF·종목·테마와 **관계(relation)로 엮여** 있어, 콘텐츠에서 관련 ETF로, ETF에서 관련 콘텐츠로 상호 이동이 가능합니다. 새 콘텐츠 유형을 논의할 때 이 관계 모델을 활용/확장할 수 있습니다.

## 5. 기술 스택 (참고)

- **프론트**: 의존성 제로 정적 프런트. 계층 분리가 하드 계약 — `logic.js`(순수 함수), `data.js`(픽스처 데이터), `render.js`/`app.js`(DOM), `explore.js`(탐색 화면).
- **백엔드**: Node 데이터 공급 계층(`server/`). provider별 분리(toss 실시간 시세, 공공데이터포털 ETF 유니버스 ~1,141종, DART 공시). `mock`/`live`/`hybrid` 모드.
- **데이터 파이프라인**: 구성종목(CSV), 메타데이터(운용사/총보수/상장일 등), 섹터·전략·배당 태깅.
- **테스트**: 98개 유닛 테스트 통과. 콘텐츠 정책·데이터 정합성 자동 검증.
